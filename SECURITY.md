# Security And Privacy

Please do not commit private keymaps, local backups, tokens, screenshots with
personal data, or device dumps that may contain private mappings.

Ignored local paths include:

- `backups/`
- `dist/`
- `vendor/`
- `hardware/snapshots/`
- `layouts/current*.json`
- `layouts/*.local.json`

If you find a vulnerability that could expose local files, write outside the
project directory, or corrupt device state unexpectedly, open a GitHub issue
with a minimal reproduction. Do not include private keymaps or secrets in the
issue.
